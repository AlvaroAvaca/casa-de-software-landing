# Criterios de aceptación

Un archivo por funcionalidad, escrito por el Arquitecto en español, en la forma Dado / Cuando / Entonces. El Probador convierte cada criterio en una prueba automática antes de que exista el código. El nombre de la prueba repite el criterio para que Álvaro lo lea en el PR.

Formato de cada archivo:
- Funcionalidad: nombre.
- Issue: número.
- Criterios: lista numerada, cada uno con Dado, Cuando y Entonces.
- Prueba: ruta en pruebas/aceptacion/.
