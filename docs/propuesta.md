## Mapa del programa (en palabras simples)
Una sola página estática con cinco secciones: Qué es, Cómo trabaja, Estado real, Cómo pedir un programa y Privacidad. Sin JavaScript en la página, sin formularios, sin analítica, sin solicitudes a otros dominios. La sección "Estado real" se genera desde un archivo de datos con evidencia, para que la página no pueda prometer de más.

## Preset y hosting propuesto (sin gastos nuevos)
- Preset: sitio-estatico del arnés (servidor sin dependencias, Playwright).
- Hosting: GitHub Pages, gratis en repo público. URL: alvaroavaca.github.io/casa-de-software-landing.
- Vista previa por PR: publicada en una subcarpeta de la misma GitHub Pages, con el token del repo; sin secretos ni servicios extra.
- Dominio propio: después, si Álvaro lo quiere, sin costo si ya lo tiene.
